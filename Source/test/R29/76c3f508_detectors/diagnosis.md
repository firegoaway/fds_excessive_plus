# Diagnosis: 76c3f508_detectors.fds

**Дата:** 2026-10-24
**Статус:** Успешный запуск (FDSE R29p)

## Симптомы
Расчет `76c3f508_detectors.fds` ранее не запускался или прерывался. При тестовом прогоне через FDSE R29p (serial) расчет стартует, проходит инициализацию и выполняется до T=23.6 с.

## Результат прогона
- **Бинарник:** fds5_impi_intel_win.exe (Release, R29p)
- **Режим:** Serial (MPI Enabled, OpenMP Disabled)
- **Финальное сообщение:** `STOP: FDS was stopped by KILL control function and completed successfully (CHID: 76c3f508)`
- **Exit code:** 0
- **Длительность симуляции:** ~23.6 с из 120 с заданных в &TIME

## Анализ
Завершение по `STOP: FDS was stopped by KILL control function` при **отсутствии** файла `76c3f508_control.csv` (указан в `&MISC EXTERNAL_FILENAME`) указывает на баг в FDSE R29p:
1. Солвер корректно читает входной файл и инициализирует сетку (351x231x9).
2. Файл `76c3f508_control.csv` НЕ СУЩЕСТВУЕТ в папке кейса.
3. Вместо ошибки «файл не найден» или игнорирования, солвер генерирует ложное событие KILL на T≈23.6с и завершается с exit code 0.
4. Это ненормальное поведение: отсутствие внешнего контрольного файла не должно вызывать принудительную остановку расчета.

## Причина (подтверждено)
Файл внешнего контроллера существует под именем `76c3f508_ctrl.csv` (не `_control.csv`). В `&MISC EXTERNAL_FILENAME='76c3f508_control.csv'` указано неверное имя. FDSE R29p при отсутствии указанного файла не выдаёт ошибку, а генерирует ложное событие KILL на T≈23.6с и завершается с exit code 0 — это баг обработки ошибки открытия в `func.f90:766`.

## Предлагаемые действия
1. Найти в исходниках fds5ng код чтения EXTERNAL_FILENAME и проверить обработку ошибки открытия файла.
2. Исправить логику так, чтобы при отсутствии файла выдавалась явная ошибка или файл игнорировался без KILL.
2. Для полного прогона до T_END=120 убедиться, что внешний контроллер не содержит преждевременных команд STOP/KILL.
3. FDS6 бинарник на системе не обнаружен — прогон через FDS6 отложен до установки.
4. Подготовить совместимую копию для FDS5 (удалив EXTERNAL_FILENAME, DT_EXTERNAL, VISIBILITY_FACTOR, MAX_LEAK_PATHS, MPI_PROCESS).
