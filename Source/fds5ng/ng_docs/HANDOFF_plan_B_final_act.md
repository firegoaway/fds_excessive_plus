## 1. Решение владельца (этап 8)

Этап 8 — точка решения владельца по итогам полного закрытия протокола §3 (этап 7).
Выбран путь «б»: реестр отложенного переноса заморожен, перенос CFL_DP_SCALE и
ITMP-клампов отменён, оформлен настоящий итоговый акт.

Основания решения:

1. Целевые критерии плана B достигнуты полностью: совместимость с входами
   FDS6/Fenix+ и прохождение протокола приёмки §3 против эталона same_but_fds6
   (пункты (а)(б)(в)(д) — PASS, §4).
2. Сценарий synth_710 (6.7 МВт/м²) — экстремальный стресс-тест, не типовой рабочий
   случай; донор-форк на нём сам нестабилен (коллапс до 3.63 МВт на 650 с),
   перенос стабилизаторов не гарантировал результата.
3. Перенос добавил бы риск регрессии на закрытых тестах и потребовал бы полного
   круга переприёмки без гарантии улучшения (природа отклонения — бистабильность
   объёмного горения, а не отсутствие механизмов).

## 2. Цель и результат плана B

Цель (родитель, §1–§2): замена базы форка на чистый FDS 5.5.3 с поэтапным переносом
валидированных механизмов. Мотивация — межфазная неустойчивость численного ядра форка
на сетке 0.5 м (CSMAG=0.2 → Numerical Instability на t=273.8 с; FLUX_LIMITER=2 →
спираль DT до 3e-5 с), блокировавшая рычаги входного файла; решение — смена базы
вместо заплаток ядра.

Результаты:

1. Совместимость: входы FDS6/Fenix+ 3.7.1.1 (0106e472_detectors — SPEC_ID_NU/NU,
   люмп-виды, детекторные цепочки DEVC/CTRL, внешнее управление CSV) читаются и
   считаются без правки входа; чистые FDS5-входы деградируют штатно (room_fire —
   без ошибок).
2. Приёмка: протокол §3 против эталона same_but_fds6 (CHID b7896c0a, FDS-6.11.1)
   закрыт полностью — (а)(б)(в)(д) PASS (§4).
3. Решатель: `fds5ng` ревизии R29e, сборка зелёная (§6).

## 7. Известные ограничения

1. Плато synth_710 (стресс-тест 6.7 МВт/м²): точка 500 с = 6.51 МВт в допуске
   6.4–6.8 МВт; после 500 с HRR осциллирует в полосе 3.9–6.5 МВт, точка 600 с =
   4.69 МВт (донор 6.83), F_INJECT 0.79–0.87. Природа — бистабильность объёмного
   горения витированного объёма с колебанием запаса несгоревшего топлива; донор на
   650 с коллапсирует до 3.63 МВт. Кандидаты-стабилизаторы (CFL_DP_SCALE,
   ITMP-клампы) заморожены (§8).
2. Амплитуда поля скорости 70–84 % эталона FDS6 при структурном соответствии
   r=0.92–0.95 (тест B, §5).
3. Визуальная приёмка выходов (.smv/.s3d) в SmokeView 6.11+ не выполнялась —
   за владельцем; структурные маркеры FDS6 в .smv присутствуют (этап 3, §4(в)).
4. Изменения R29a–R29e существуют только в рабочем дереве `Source/fds5ng`;
   коммиты по правилам сессий плана B не выполнялись. Бинарники промежуточных
   ревизий перезаписаны; состояние финальной ревизии R29e воспроизводимо сборкой
   текущего дерева. Фиксация в git — решение владельца.
5. Эталонные бинарники FDS6 на машине (6.5.3–6.9.1) не совпадают с версией эталона
   6.11.1; comparisons с эталоном — только по файлам прогонов (test/R28q_test/).
