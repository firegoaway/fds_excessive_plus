## 4. Объёмная метрика по кадрам .s3d — реальное различие

Формат: opacity-байт = 254·(1−exp(−τ)), τ = k·ρ_s·dx, k=8700, dx=1 м;
насыщение (τ>3) — байт ≥242; колено (0,7<τ<3) — 129–241. Буфер меша —
узлы (IBAR+1)×(JBAR+1)×(KBAR+1). Ориентация мешей (TRNZ): **меш 1 =
z=3..6 м (верхний объём), меш 2 = z=0..3 м (нижний)**; DEVC z=1,5 — в
меше 2, DEVC z=4,5 — в меше 1.

Меш 1 (z=3..6), доля ячеек на t=690 с (зеркало R29f / эталон FDS6):

| Слой | NG sat τ>3 | FDS6 sat | NG knee | FDS6 knee |
|---|---|---|---|---|
| k=1 (z≈3) | 41,2 % | 0,5 % | 3,3 % | 36,2 % |
| k=2 (z≈4) | 44,7 % | 0 % | 6,8 % | 31,8 % |
| k=3 (z≈5) | 46,0 % | 0 % | 14,6 % | 35,3 % |
| k=4 (z≈6) | 44,0 % | 0 % | 12,9 % | 39,0 % |
| весь объём | 44,0 % (32 140) | 0,1 % (85) | 9,4 % | 35,6 % |

Развязка с точками: глубокие точки (VIS<0,3 м) — 81 у NG и 77 у FDS6; у
эталона ровно ~85 насыщенных ячеек, т.е. его плотное ядро компактно и
накрывает те самые точки; зеркало разливает умеренную плотность
(max_dens 2,12e-3 против 2,97e-3) по 44 % объёма выше колена.

**Итог:** наблюдение владельца подтверждено объёмной метрикой — у зеркала
верхний объём равномерно перенасыщен (сплошная чернота без градиентов), у
эталона — компактное ядро плюс 36 % объёма в зоне видимых градиентов.
Точечные DEVC (1,2 % покрытия клеток) этого различия не видят. Верх z=0..3
(меш 2) у обоих чист — «дым снаружи на юге/востоке» относится к верхнему
объёму. Гипотеза-кандидат: дефицит перемешивания/разгона (тест B: амплитуда
|V| 70–78 % эталона) — дым переносится, но не разжижается до колена.

## 5. E-прогоны: две попытки и вердикт

**Попытка 1 (невалидная, задокументирована):** авто-цепочка R29h на входе
detectors.fds (каталоги `fds5ng_e_runs/e_a/e_b/e_c`). Причина невалидности:
`b7896c0a_finish.fds` — не «detectors+RESTART», а иная постановка источника
(Fenix+ разворачивает результат стадии 1 в полную кривую `&RAMP RAMP_1
T=153..690 F=0.0001..0.0023` вместо интерактивного CTRL_1/RAMP_2). Прогоны
«detectors дважды» дают HRR ≈3 МВт после 41 с — источник стадии 2 не
воспроизводится. Каталоги оставлены как иллюстрация.

**Попытка 2 (валидная):** церемония базы — стадия 1 detectors без патча до
KILL 41,3 с (одна на все варианты), обрезка выходных рядов до t≤41,3
(csv/.sz/бинарные .s3d/.s3dd по записи), затем в каждом варианте стадия 2
finish.fds с патчем &MISC. Дефолты NG: FLUX_LIMITER=4, CSMAG=0,20; E-B по
букве ментора (CSMAG=0.2) совпал бы с базой — заменён на 0,15.

Итоговая матрица (меш 1, z=3..6; sat%/knee%; HRR МВт):

| Прогон | t=312 | t=600 | t=690 | HRR 600/689 | DT min |
|---|---|---|---|---|---|
| Эталон FDS6 | 0/0,2 | 0/13,8 | **0,1/35,6** | 70,7/84,7 | — |
| База R29f | 0,3/25,8 | 41,2/7,4 | **44,0/9,4** | 62,8/84,7 | 0,034 |
| E-A2 FLUX_LIMITER=2 | 0,9/24,9 | 39,9/7,4 | **41,3/6,5** | 61/82,9 | 0,011 |
| E-B2 CSMAG=0.15 | 0,1/27,7 | 41,6/7,4 | **44,5/8,3** | 64,3/76,7 | 0,020 |
| E-C2 оба | 0,2/26,5 | 40,3/7,2 | **42,7/7,7** | 62,9/88,1 | 0,009 |

**Вердикт:** оба рычага неэффективны — доля насыщения меняется в пределах
±2–3 п.п. (44 % → 41–44,5 %) при эталоне 0,1 %. SUPERBEE дополнительно
прижимает DT к границе устойчивости (минимумы 0,009–0,011 против 0,034
базы; критерий убийства DT<0,01 задет в E-C2). HRR во всех вариантах в
полосе базы. Различие с эталоном устойчиво к константной подсеточной
вязкости и выбору лимитера потоков — остающийся кандидат: динамическая
модель Смагоринского FDS6 (и/или схема переноса скаляра), не эмулируемая
рычагами входного файла.

## 4-бис. Следствия (уточнены по объёмной метрике §4)

1. Симптом «сплошная чернота после ~600 с» — реальное объёмное различие
   (44 % против 0,1 % насыщения верхнего объёма), а не рендер и не артефакт
   данных; зубцы — изолиния порога на клеточном поле.
2. Низ (z=0..3) у обоих чист; различие локализовано в верхнем объёме
   (меш 1, z=3..6).
3. E-прогоны (§5) проверяют рычаги перемешивания; решение о смене дефолтов
   NG — за владельцем по их итогам.

Среда: парсеры инвариантной культуры, исходники не менялись, коммитов нет.
