## Чек-лист для ручного тестирования владельца в Fenix+

1. В настройках расчётного ядра Fenix+ указать `...\Build\impi_intel_win_ng\dist\fds5ng.exe`.
2. В переменных окружения запуска Fenix+ (или системно) выставить `FDS5NG_NO_CHAIN=1`.
3. Прогнать знакомый сценарий (например, 0106e472 / Строение 5) до конца.
4. Смотреть: чтение входа, остановку на извещателе, карточки извещателей
   (сработки), рестарт стадии finish, непрерывность кривых, рендер дыма/огня.
5. Каталог прогона при любой аномалии — сохранить целиком для разбора.

## R29s (следующий шаг после R29r)

Mesh-embedding перенесён (opt-in: EMBEDDED_MESH=.TRUE. на &MISC + контроли R28l).
Остаток: embedding×пожар нестабилен в NG (донор проходит) — нужен порт донорных
COMBUSTION-стабилизаторов (ghost-HRR губернатор BUG#11, антидетонационные лимиты
DZ_CAP/MIX_TIME) из fds5/fire.f90 в fds5ng/fire.f90 как R29t. До этого embedding
использовать только для сценариев без прописного горения на тонких мешах.
