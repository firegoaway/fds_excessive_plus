- «DEVC_8 VIS20, 1.83 с» — DEVC_8 есть RADIATIVE HEAT FLUX GAS, колонка
  постоянна на уровне ≈0.53 кВт/м² с первых кадров; условие «0 < v <= 20»
  срабатывает на первом ненулевом кадре (1.83 с). Вклад «only-mirror 43» и
  «ранний приход дыма» — этот механизм.
