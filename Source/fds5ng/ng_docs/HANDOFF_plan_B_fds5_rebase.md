# HANDOFF: план B — ребейз на чистый FDS 5.5.3 с переносом валидированных механизмов

Версия: 1.0
Дата: 2026-09-24
Статус: подготовлен по решению владельца; запуск — после его явной команды.

## 1. Контекст и причина перехода

Форк fds_excessive_plus (ревизии R19–R28z) доведён до устойчивого состояния:
откат режима A (FLAME_SHEET, R28w), экстрем-режим R28x (динамический предел q_dyn +
P-троттлинг впрыска F_INJECT, авто-гейт по эффективным HRRPUA > 3 МВт/м² с учётом
максимума рампы), валидированы на сценариях synth_710 (6.7 МВт/м², 710 с, DT>=0.03
на 100 % времени) и запертом синтете 60 МВт (STOP success).

Не достигнута визуальная парity с FDS6 (нитевидность дыма). Оба рычага входного
файла заблокированы одной причиной — межфазной неустойчивостью численного ядра
FDS5 на сетке 0.5 м:

- CSMAG=0.2 (дефолт FDS6): Numerical Instability на t=273.8 с (эксперимент R28y);
- FLUX_LIMITER=2 (SUPERBEE): спираль DT до 3e-5 с на t=122.09 с после рестарта,
  лидер нормы сменился на дивергенцию (DP share 0.86–0.92 против 0.01 в базовой
  линии), максимум дивергенции в первом слое над границей мешей z=3 — межфазная
  мода (эксперимент E2′).

Штатная схема FDS5 (FLUX_LIMITER=-1, EPS-корректированный плотностной транспорт,
mass.f90:84-157) устойчива, но диффузионнее SUPERBEE+динамической Смагоринского из
FDS6 — отсюда «войлок». Решение: сменить базу, а не латать ядро.

## 2. Целевая архитектура плана B

База: чистый FDS 5.5.3 из E:\FIREGOAWAY\GitHub\FDS5\FDS_Source (свежая копия,
НЕ текущий форк). На неё переносится по частям, с ревизионными тегами R29+:

1. Слой совместимости FDS5-FDS6 (из форка, read.f90/dump.f90):
   - толерантное чтение/игнорирование конструкций FDS6;
   - ламповые AIR/PRODUCTS, SPEC_ID_NU/NU;
   - DEVC/CTRL-величины FDS6, EXTERNAL-функции с CSV;
   - экспорт Fenix+ 3.7.1.1 (PROC_CTRL, ограниченный цикл по SIZE(INPUT_ID));
   - выходные файлы читаемы SmokeView и постобработкой FDS6.
2. HCl: трассировка HYDROGEN CHLORIDE как продукта (логика извлечения из
   PRODUCTS — форк R28j, read.f90: печать «Extracted N components»).
3. Все неймлисты и параметры, которые принимает ридер форка; деградация без
   ошибок на чистом FDS5-входе.
4. Simple Chemistry (одностадийная), SOOT_YIELD вычисляется из прочих YEILD
   &REAC (CO_YIELD и др.) при разложении PRODUCTS — перенос расчёта R28j:
   трассер продуктов 3.389 кг/кг, SOOT 7.035E-02 кг/кг для кейса 0106e472.
5. Валидированные предохранители (переносить только целиком, с тестами):
   - GOVERN_HRR + DZ_CAP=0.25 (главный.f90, fire.f90, main.f90:957-1010);
   - R28x: DT_TARGET/CFL_TARGET, q_dyn в COMBUSTION_MF (fire.f90), F_INJECT
     (main.f90, wall.f90:464), авто-гейт по HRRPUA_MAX с учётом рампы
     (read.f90:5855, PROC_SURF_2);
   - DT_GUARD (R22).
6. НЕ переносить: режим A (FLAME_SHEET целиком, включая RT-демпфер velo.f90),
   ядра R28s/t/u, стенсиль-разбавление.

    (b7896c0a_devc.csv; у эталона 4 колонки sz: t nin nout max).
Синтеты: экстрем synth_710.fds (6.7 МВт/м²) и запертый r28q_synth2.fds (60 МВт).
