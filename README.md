# fds_excessive_plus

Глубоко переработанный гибрид FDS 5 и FDS 6, предназначенный для выполнения пожарно-технических расчётов по российским методикам.

## Назначение

Решатель пожарной динамики на базе FDS версии 5.5.3 (кодовая ревизия R28e) рассчитывает развитие пожара в зданиях методом крупных вихрей. Тепловыделение задаётся по предписанным кривым Приложения №1 Методики №1140 МЧС России. Входные файлы формата `.fds` читаются без адаптации; поддерживаются файлы, подготовленные вручную и экспортированные из Pyrosim, Fenix+ и UrbanPO. Выходные файлы полностью совместимы с SmokeView и инструментами обработки FDS6.

## Режимы работы

Решатель предоставляет два режима тепловыделения, разделённые по пространственному разрешению сетки.

1. **Режим заданного профиля тепловыделения** (`FLAME_SHEET=.TRUE.` в группе `&MISC`) — для грубых сеток с шагом не менее 0.5 м. Тепловая мощность следует заданной функции `RAMP_Q` или `TAU_Q` с машинной точностью и распределяется по коническому объёму источника с ограничением локальной объёмной плотности тепловыделения.
2. **Полное моделирование горения по модели EDC** (режим по умолчанию) — для мелких сеток с шагом не более 0.25 м. Скорость реакции ограничивается временем турбулентного смешения и локальным пределом плотности тепловыделения 2500 кВт/м³.

На сетке с шагом 0.25 м режим заданного профиля теряет межфазную устойчивость границы слоёв газа при выходе мощности на плато; на этом разрешении применяется полное моделирование горения.

## Численные характеристики

Контрольный сценарий: открытая планировка, пиковая мощность 21 876.7 кВт, физическое время 500 с, сетка с шагом 0.5 м.

| Показатель | Модель EDC | Режим заданного профиля |
|---|---|---|
| Число шагов по времени | 60 302 | 4 996 |
| Машинное время | около 9 ч | 0.87 ч |
| Коэффициент ускорения по числу шагов | — | 12.1 |
| Ускорение по машинному времени | — | 10.3 |

Кривая тепловой мощности в режиме заданного профиля воспроизводит функцию `RAMP_Q` точно. Энергетический баланс составил 1.005. Интеграл скорости газификации воспроизводится с погрешностью 0.2 %. Время срабатывания пожарных извещателей на массиве из 7290 контрольных точек укладывается в допуск 10 % для 2822 точек.

Второй контрольный сценарий: замкнутое помещение, плато мощности 7656.8 кВт, длительность 350 с, сетка с шагом 0.5 м. Расчёт выполнен за 4 564 шага и около восьми минут машинного времени на одном процессе; плато мощности выдержано точно.

## Совместимость

Подсистема совместимости в `read.f90` и `dump.f90` обеспечивает:

- чтение, преобразование и контролируемое игнорирование конструкций синтаксиса FDS6;
- объединённые смеси `AIR` и `PRODUCTS`; задание реакции параметрами `SPEC_ID_NU` и `NU`;
- величины `DEVC` и `CTRL` версии FDS6; управляющие функции `EXTERNAL` с вводом из CSV-файлов;
- обработку экспортов Fenix+ 3.7.1.1, включая итерирование `INPUT_ID` ограниченным циклом (устраняет аварийное завершение на конструкциях `INPUT_ID(1:40)`);
- сохранение выходных файлов в форматах, читаемых SmokeView и средствами обработки FDS6.

## Ключевые параметры

| Параметр | Группа | Значение по умолчанию | Назначение |
|---|---|---|---|
| `FLAME_SHEET` | `&MISC` | `.FALSE.` | Включение режима заданного профиля тепловыделения. |
| `FLAME_SHEET_QCAP` | `&MISC` | 500 кВт/м³ | Верхняя граница объёмной плотности тепловыделения в объёме источника. |
| `FLAME_SHEET_HMAX` | `&MISC` | 0 м | Верхняя граница высоты объёма источника; 0 отключает ограничение. |
| `FLAME_SHEET_TAU` | `&MISC` | 0 с | Постоянная времени тепловой буферизации конуса источника; 0 отключает. |
| `AUTO_ZONE` | `&MISC` | `.FALSE.` | Автоматическое зонирование замкнутых объёмов. |
| `STRICT_POCKETS` | `&MISC` | `.TRUE.` | Зонирование замкнутых газовых карманов. |

Контроллер шага по времени удерживает число Куранта в диапазоне от 0.8 до 1.0: при превышении шаг умножается на 0.9, при падении ниже нижней границы — на 1.5. Вес дивергентного члена в норме Куранта задаётся константой `CFL_DP_SCALE` и равен единице.

## Сборка

Операционная система Windows; инструментарий Intel oneAPI (компилятор ifx 2025.3.0), Intel MPI и MKL.

```
cmd /c "cd /d <репозиторий>\Build\impi_intel_win && make_fds5.bat"
```

Отладочная сборка выполняется сценарием `make_fds5_debug.bat`. Основной make-файл решателя — `Build\makefile5`.

| Путь | Содержимое |

## Ограничения

Режим заданного профиля не учитывает потребление кислорода: мощность задаётся функцией `RAMP_Q` независимо от локального состава газа. Характеристики ближнего поля очага рассчитываются приближённо вследствие принудительного распределения тепловыделения по коническому объёму. Возможность перезапуска из сохранённого состояния в середине сценария заявлена как алгоритмический инвариант и не проверена прямым численным экспериментом.
